## 运单信息所需字段

| 英文键 | 中文名称 | 
| ------------------ | ------- |
| `vehCode`        | 车牌号码     |
| `ton`            | 车辆核定载质量  |
| `vehicleType`    | 车辆类型     | 
| `driverName`    | 驾驶员姓名      |
| `driverTel`     | 驾驶员电话      |
| `billNo`           | 电子运单编号     |
| `billState`        | 运单状态        | 
| `billCreateTime`   | 运单创建日期     |
| `receiveName`      | 收货单位名称     |
| `loadingDate`      | 计划装货日期     |
| `unloadingDate`    | 计划卸货日期     |
| `goodsInfo`        | 货物详细信息     |
| `lineName`         | 运输线路名称      |
| `lineMile`         | 线路里程        |
| `approvalTime`   | 审批时间 |
| `approvalResult` | 审批结果 |



### `approvalResult` | 审批结果 
> 0 = 待审批
> 1 = 通过
> 2 = 驳回
